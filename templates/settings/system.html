Режим витрины

Для скриншотов и показа панели на экране. Названия точек и групп, адреса, имена устройств за роутером, MAC и учётные записи заменяются вымышленными: адреса берутся из диапазонов, отведённых под примеры, а MAC собираются так, что не принадлежат ни одному производителю. Подмена живёт только в ответе браузеру, база не меняется. Режим включается для вашего браузера и держится {{ demo_hours }} ч: остальные в это время видят настоящие данные.
Это удобство, а не защита. Тот, кто уже вошёл в панель, видит настоящие данные в любой момент.

Рекомендации по безопасности

Доступ к панели: {% if diag.admin_networks %} только из сетей {{ diag.admin_networks }}. Публичный лист состояния при этом открыт всем, как и задумано. {% else %} откуда угодно.   • Заведите на MikroTik отдельного пользователя для Tikpilot с минимальными политиками (api, read, write, test, ftp, плюс reboot, если нужны перезагрузки) и ограничьте ему allowed-address адресом сервера.
  • Пароли устройств хранятся в базе зашифрованными (Fernet). Ключ лежит в data/fernet.key, сделайте его резервную копию и ограничьте доступ.
  • Публикуйте интерфейс только через HTTPS-реверс-прокси и включите COOKIE_SECURE=1 в .env.
  • Смените пароль администратора по умолчанию сразу после первого входа.
