Касается терминала и команд по SSH. Всё остальное ходит по API с паролем
Целиком, вместе со строками BEGIN и END. Без пароля на ключе: панель ходит на точки сама, вводить его будет некому. Публичную часть заранее положите на роутер.
Панель узнаёт оператора у LTE-модема, а при включённой настройке OPERATOR_LOOKUP и по публичному адресу точки. Заполненное здесь сильнее: следующий опрос его не затрёт. Сюда же удобно писать номер договора.
Адреса через запятую. Устройство пингует их само во время полного опроса. Шлюз по умолчанию добавляется автоматически.
