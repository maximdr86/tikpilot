## Перед публикацией

**Включите режим витрины**: Настройки → «Режим витрины». Названия площадок,
адреса, имена клиентов, MAC, ключи WireGuard, имя пользователя API и учётные
записи заменятся вымышленными, включая имя в левом меню. Пока режим включён,
там же висит розовая плашка «витрина», и её видно на снимке: снимайте так,
чтобы она не попадала в кадр, либо обрежьте низ меню.

Режим включается только для вашего браузера и гаснет через 8 часов. Замазывать
после него нечего, но снимок всё равно стоит просмотреть глазами: в свободном
тексте (комментарии, логи с устройств) может остаться то, чего в базе нет.

Снимать лучше на английском интерфейсе: репозиторий читают в основном
не по-русски. Вымышленные имена на нём тоже английские.

## Технически

- Ширина окна 1440–1600 px, масштаб браузера 100%.
- Светлая тема (она по умолчанию) — на GitHub читается лучше.
- PNG, не JPEG: скриншоты интерфейса с текстом JPEG портит.
- Прогоните через `pngquant` или `oxipng`, если файл больше 500 КБ.
