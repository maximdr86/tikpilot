## Перед публикацией

**Проверьте, что замазано всё.** На экранах панели видны названия площадок,
внутренние адреса, имена клиентов и имя пользователя API. Замазывать нужно
и левое меню: имя учётной записи стоит рядом с пунктом «Настройки».

Снимать лучше на английском интерфейсе: репозиторий читают в основном
не по-русски.

## Технически

- Ширина окна 1440–1600 px, масштаб браузера 100%.
- Светлая тема (она по умолчанию) — на GitHub читается лучше.
- PNG, не JPEG: скриншоты интерфейса с текстом JPEG портит.
- Прогоните через `pngquant` или `oxipng`, если файл больше 500 КБ.
